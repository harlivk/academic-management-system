# Academic Management System

A web-based Academic Management System built using Django, designed to streamline academic activities through dedicated student and teacher portals.

## Live Website

https://academic-management-system-meqt.onrender.com/

## Key Features
- Student registration and login
- Student dashboard
- Teacher registration and login
- Teacher dashboard
- Attendance management
- Assignment and marks management
- Role-based access

## Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** Neon (PostgreSQL)
- **Deployment:** Render
